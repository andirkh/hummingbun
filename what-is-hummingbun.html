What is Hummingbun?

Hummingbun is a minimalist static site generator crafted for the modern web builder. Like a hummingbird darting through a garden, it moves with grace and speed.

Built for Bun, it transforms your content into a beautiful, fast static site. No complexity. No unnecessary overhead. Just pure, crystalline simplicity.

  • Lightning fast — Compiles in milliseconds
  • Artfully simple — Markdown in, HTML out
  • Beautifully styled — Powered by Kinu CSS
  • React-ready — Uses Preact for interactive moments

Write your story. Let Hummingbun paint it on the web.
