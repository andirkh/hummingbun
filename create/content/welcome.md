# Welcome to Hummingbun

This is your first page. Edit this file to create your own content.

## Get Started

1. Edit the content in `content/` directory
2. Customize the design in `template/` and `static/main.css`
3. Update `hummingbun.tsx` with your site's information
4. Run `bun run build` to generate your site

## What's Next?

Create new markdown files in the `content/` directory. They'll automatically become pages on your site.

Hummingbun makes static site generation simple and delightful. Let your creativity flow.
