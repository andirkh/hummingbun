# $PROJECT_NAME

A beautiful site powered by Hummingbun.

## Getting Started

```bash
bun install
bun run build
```

The generated site will be in the `dist/` directory.

## Development

To rebuild on file changes:

```bash
bun run dev
```

## Deployment

Push to GitHub and the workflow will automatically deploy your site to GitHub Pages.

## Customize

1. Edit `hummingbun.tsx` to configure your site
2. Add content as Markdown files in `content/`
3. Update `template/` files to change the design
4. Add styles to `static/main.css`
